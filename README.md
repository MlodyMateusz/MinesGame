# Plan Projektu - Mines Game

## Intefejs graficzny:
- stworzenie głównego menu aplikacji,
- dodanie zakładek przy użyciu TabbedPage,
- przygotowanie okna gry,
- przygotowanie okna historii,
- przygotowanie ustawień użytkownika,
- dodanie customowych fontów,
- dodanie obrazów w formacie PNG
  
---

## Implementacja gry:
- stworzenia planszy 5x5,
- generowanie min w losowych miejscach na planszy,
- obsługa kliknięć pól,
- odkrywanie pól,
- sprawdzanie, czy gracz wygrał lub przegrał,
- implementacja balansu gracza,
- dodanie systemu mnożników,
- dodanie systemu Cash Out (możliwość wypłaty przez gracza w dowolnym momencie gry, o ile nie przegrał),
- dodanie możliwość ustawienia:
  - ilości min,
  - wysokości stawki
    
---

## Baza danych:
- pobranie NuGeta SQLite,
- konfiguracja SQLite,
- stworzenie modelu historii gier,
- zczytywanie historii,
- wyświetlanie danych w CollectionView
  
---

## Zapisywanie ustawień:
- zapis nazwy użytownika,
- zapis balansu gracza,
- wykorzystanie SharedPreferences

- ujednolicenie kolorystyki
